# 一期九科课程覆盖矩阵

> 版本：2026-11-06  
> 适用范围：孩子当前六年级下半程，先扎实补真实薄弱点，再衔接人教版初中；天津中考作为长期边界。  
> 本文件是排课与审课依据，不是学习成绩单。

## 1. 口径与成功标准

### 1.1 四个概念必须分开

- **已有页面**：课程文件、入口、记录和离线资源存在，只证明产品可打开。
- **局部覆盖**：某个概念已有一课或一个切口，不能替代整章或完整能力链。
- **已成链**：至少有“前置概念 → 原理或方法 → 新情境迁移”的相邻课程；仍可能缺少章节中的其他知识。
- **孩子掌握**：必须有未提前看答案的新情境作答证据，最好再有间隔复测；“看懂演示”“完成页面”“订正后答对”都不能单独算掌握。

因此，一期进度不使用一个看似精确的总百分比。课程数量、知识覆盖和孩子掌握是三种不同进度，分别记录。

### 1.2 模块完成门槛

一个模块只有同时满足以下条件，才可由“缺失/局部”升级为“已成链”：

1. **定位准确**：写明现行课标、人教教材或天津考试中的位置。
2. **概念严谨**：先解释为什么成立，再给规则；说明适用边界与常见反例。
3. **行动验证**：动画只展示难以看见的关系，文字紧贴对应位置。
4. **支架递减**：短示例与独立尝试交替，提示逐步撤掉。
5. **真正迁移**：改变故事、信息形式或所需方法，不只替换数字。
6. **过程留痕**：保留首答、提示、修订与孩子自己的解释。
7. **工程自检**：内容、交互、移动端、学习记录、离线入口和公开页面均验证。

### 1.3 优先级

- **P0**：当前六年级薄弱点、七上关键前置，或会阻塞多门后续课程的基础。
- **P1**：初中主干与天津考试的重要能力链，按前置关系逐步补齐。
- **P2**：较晚年级模块、综合提升与长期扩展；不越过必要前置抢跑。
- **有条件启动**：考试重要，但教材版本、事实来源或安全审校条件尚未齐备。

## 3. 九科模块矩阵

### 3.1 数学

主线依据：数与式，方程与不等式，函数；图形的性质、变化与坐标；统计与概率；综合与实践。

| 模块 | 当前课程映射 | 状态 | 断点与前置 | 优先级 / 下一候选 |
| --- | --- | --- | --- | --- |
| 有理数概念与运算 | `negative → addition → subtract → multiply → quotient → power` | 已成链（科学记数法等未专项） | 小学整数、分数、小数四则 | P0 间隔换情境复测，不再连续堆同类课 |
| 代数式与整式加减 | `liketerms → brackets` | **局部小链** | 有理数、乘方、分配律、字母表示数 | P0：间隔迁移后再接方程中的去括号，不连续堆机械计算 |
| 一元一次方程 | `liketerms → brackets → equation`；错题站含工程问题 | **基础小链已成** | 已建立同类项、去括号、等式性质与两步方程；复杂方程仍缺 | P0：先做间隔换情境复测，再补移项、去括号方程、去分母与建模 |
| 实数、方程组、不等式 | 错题站只有少量消元切口 | 缺失 | 有理数、整式、一元一次方程 | P1：实数 → 坐标 → 方程组/不等式 |
| 坐标与函数 | `journey`、`charts`为读图预热 | 局部预热 | 数轴、实数、整式、方程 | P1：坐标系 → 变量关系 → 一次函数；再到反比例、二次函数 |
| 角、相交线与平行线 | `angle180 → parallel` | 已成链 | 点、线、角与几何语言 | P0/P1 换图、换信息形式复测 |
| 三角形与多边形 | `triangle180 → polygon360` | 较强局部 / 已有证明链 | 平行线与辅助线 | P1：边、三线、全等、等腰、勾股、相似、三角函数 |
| 图形变换 | `rigidmotion`；`scale`为缩放预热 | 局部 | 全等、坐标、比例 | P1：轴对称、旋转、平移、相似判定与证明 |
| 四边形、圆、视图 | `math`仅为六年级圆与方圆组合 | 局部 / 大部缺失 | 三角形、全等、相似 | P1/P2：平行四边形 → 圆的性质与证明 → 投影视图 |
| 统计与概率 | `weighted`、`charts` | 局部 | 百分数、数据读图 | P1：收集/抽样/频数 → 平均数/中位数/众数/方差 → 概率 |
| 数学思维扩展 | `balance` 等 | 局部扩展 | 依所用主干知识而定 | P2：爬楼梯、分类讨论、反证等；必须回挂主线，不替代教材 |

建议主链：

`有理数（已有） → 整式加减 → 一元一次方程深化 → 实数 → 坐标系 → 方程组/不等式 → 一次函数`

几何并行链：

`角 → 平行线 → 三角形内角和 → 多边形内角和 → 全等三角形 → 轴对称/等腰 → 勾股 → 四边形 → 相似 → 圆`

### 3.2 语文

语文不按“每课固定五题”压缩。一般采用全文或完整材料，在语境中完成词汇、句式、结构、表达手法和阅读方法的递进。

| 模块 | 当前课程映射 | 状态 | 断点与前置 | 优先级 / 下一候选 |
| --- | --- | --- | --- | --- |
| 语言积累与梳理 | `repair`、`chinese`、`qualifier`、共读点注 | 局部 | 字音字形 → 词义语境 → 句意 → 段意 | P0：建立六升七连续链，不做孤立抄写 |
| 一般阅读能力 | `gist → reading → qualifier → causal → character` | 素材较多，链未完全闭合 | 整体感知、思路、证据、推断、中心 | P0：用完整文章连续训练“初读—梳理—取证—解释” |
| 文学阅读 | 《春》《百草园》《背影》及人物课 | 局部，偏散文 | 一般阅读 → 体裁要素 → 审美评价 | P0/P1：补诗歌、小说、戏剧；保持全文与点读注释 |
| 文言文 | 《陈太丘与友期行》 | 起步 | 实词虚词 → 句意 → 事件链 → 人物/主旨 → 比较 | P0：按七上篇目形成连续链，不靠逐字翻译背答案 |
| 古诗词 | 无 | **缺失** | 节奏、画面、意象、情感、手法 | **P0：`景物都看懂了，诗人的心情从哪里来？`** |
| 实用、说明与非连续文本 | `causal`、`qualifier`、`reading`可复用 | 弱覆盖 | 信息提取 → 关系判断 → 多材料整合 | P1：说明文、新闻、图表、通知各建完整材料课 |
| 思辨与议论性阅读 | 无独立链 | 近空白 | 事实/观点 → 证据充分性 → 论证与反驳 | P1：从短论证进入，不先背术语 |
| 写作与修改 | `focus` | 很弱 | 句 → 段 → 完整事件 → 结构中心 → 修改 | P0/P1：记事写人写景、审题立意、结构详略、语言修改 |
| 整本书阅读、口语交际与专题学习 | 单篇共读不能替代 | 弱覆盖 | 持续阅读、摘记、讨论、成果表达 | P1/P2：跟教材名著和真实交流任务走 |

| 中华优秀传统文化与革命传统 | 无 | 缺失 | 应贯穿其他主题，不堆孤立知识 | 有条件 P1 |
| 国情、国家制度、世界与担当 | 无 | 缺失 | 前述概念、权威时政材料 | 有条件 P1/P2 |

启动前必须满足：

1. 获取孩子学校实际使用的新人教版册次、目录或教材页。
2. 建立“教材原句—现行法律—官方时政”三层来源表。
3. 每课增加事实、法条和规范表述专项自检。
4. 用“情境识别—概念调用—材料对应—规范表达”设计，不做泛泛辩论或只查书抄句。

## 4. 下一阶段排课

### 4.1 当前最短主线

1. **数学 M-A01（已完成）**：`字母式长得很像，哪些真的能合并？——从数走向式`
2. **数学 M-A02（已完成）**：`括号里的式子，拆开后还一样吗？`
3. **数学 M-A03（已完成）**：`等式变了，原来的答案还在吗？`

选择理由：有理数链已经存在，孩子也接触过乘方；三课把“能否合并—怎样展开—怎样保持同一个答案”接成最短代数桥梁。M-A03 审完后不立即堆同类计算，先安排间隔迁移，再决定进入移项深化还是切换学科。

### 4.2 并行但不同时堆叠的候选

- 语文：古诗词第一课 → 连续文言链 → 一般阅读完整文章 → 体裁与写作。
- 英语：短阅读＋3—4句真实回复，把已有口语优势接到读写；语音拼读以短频练习穿插。
- 历史：春秋战国 → 秦统一 → 汉代巩固，延续史料实证方法。
- 生物：未知生物分类档案；地理：公转、直射点与四季。
- 物理、化学：暂不靠零散现象课抢跑；先按教材前置补主链。

每完成一课，一课一审；只有审过当前课，才进入同一知识链的下一课。

## 5. 暂不纳入一期课程制作的项目

按当前约定，以下项目先记入待办，不计入九科课程缺口，也不用于拉高或拉低一期进度：

- 体育与健康的现场测试和专项训练。
- 物理、化学、生物的线下实验操作考核。
- 信息科技。
- 艺术（音乐、美术）。
- 综合实践活动。

线上课程可以为实验设计、数据记录和安全意识打基础，但不能替代真实器材操作、体育现场表现或学校等级认定。

# 好奇心小站

适合 iPad 和电脑的轻量学习站：

- 数学：圆的周长、面积及与正方形组合的互动演示，5 道强化练习。
- 数学：迷你火箭比例尺，含缩放动画、单位换算与正反推算，5 道强化练习。
- 数学扩展：9 个果子找更重者，可操作天秤、最少次数的推理与 5 道多维度练习。
- 语文：直接引语改转述句的技巧与 5 道强化练习。
- 英语：机器人小狗主题的口语与词汇练习，5 个小任务。
- 探索：火箭为什么要回收，含一级回收动画、可调模拟账本与 5 道强化题。
- 探索：两张图都没造假，为什么结论相反？先判断，再拖动柱状图纵轴验证；共 5 题，涵盖读图、增幅、辨错、迁移与独立表达。结束页保留首答和帮助使用情况，便于截图反馈；记录自动保存在本机，不上传。

首页以「TY敏捷课堂」承载数学、语文、英语，以「马斯克的太空学校」提供选学探索课。

用 Safari 打开网站，选择「分享 → 添加到主屏幕」。首次联网完整打开后，站内核心内容可离线访问。英语示范音频随站点提供；口语录音只保留在当前页面内存中，不上传，离开后清除。

这是无需构建的静态网站。GitHub Pages 从 main 分支根目录发布；所有资源使用相对路径。更新内容时同步调整 sw.js 中的缓存版本。

## 学习反馈

所有七课均保持固定 5 题 / 任务。六门旧课已补齐本次反馈页：保留首次提交、重试次数、答前 / 答后的提示和回看，以及综合题原话。数学、比例尺、天秤和语文将一句理由融入原有第 5 题；火箭课保留建议表达；英语第 3、4 题文字可选，第 5 题留一句英语原话。均可如实选择暂时不会或仍需帮助，不额外增加第 6 题。

- 首页「学习记录」按课程和时间查看每次练习，未完成记录也能展开截图。首次答案、重试、帮助、原话及未提交草稿边做边存；刷新后继续未完成题目，重做 5 题另存一次，保留旧记录。
- 使用当前浏览器的 localStorage，不发送作答内容到服务器。换设备、换浏览器或从 Safari 换到独立桌面入口，不保证共享记录；清理网站数据会清除。存储受限或已满会显示保存失败，不自动删旧记录。外部求助无法自动识别，未打开帮助不等于已经独立掌握。
- 天秤反馈还记录称量、重新开局和自动摆法；重新开局保留本题之前的尝试。刷新会恢复该局的偏重果子、摆法、候选与称量次数。
- 英语首段录音可在反馈页回听，重录保留首段；主动删除会清除相应录音，离开页面也会清除。没有自动转写或语音评分，截图仅含文字证据与使用情况。
- `learning-feedback.js` / `.css` 提供共享记录与样式；为保留单文件离线能力，`lessons/chinese.html` 和 `lessons/math.html` 的 sandbox srcdoc 内嵌相同代码。更新共享逻辑时需同步这两份内嵌副本。图表课接入同一记录库，保留其判断与坐标轴实验流程。
- 圆课维持 `sandbox="allow-scripts"`：外层注入仅圆课的已有记录，内层通过校验 iframe 来源的 postMessage 保存到同源记录库，不开放同源沙箱权限。
- 记录格式带版本号，每次练习独立存储键；读取时跳过不可读记录并原样保留。服务工作线程更新只替换静态资源缓存，不清除学习记录。

## 导出与恢复

学习记录页提供「导出学习记录」和「导入备份」，不改变孩子的自动保存或固定 5 题流程。

- 导出当前入口的全部课程、全部练习为一个带时间的 UTF-8 JSON 文件，不受课程筛选影响。可直接发给 AI 分析，或保存在 iPad「文件」中；不含录音。
- 新设备打开同一小站，在学习记录页导入文件。原话、首答、帮助、草稿、时间和续练状态一并恢复。导入过程在设备内完成，不上传文件。
- 文件格式为 `curiosity-station-learning-backup`，版本 1。导入先校验完整文件，再追加记录；不覆盖已有键。使用内容指纹去重，导入记录采用确定性 ID，继续学习后重复导入旧文件也不会重复添加该快照。不同进度另存，显示「备份恢复」。
- 文件损坏、格式不兼容或超过 20 MB 时不导入；写入空间不足时显示已导入与尚未写入的数量，保留原文件可重试。记录不会自动同步，清理网站数据前应先导出。
- `learning-backup.js` 仅由记录页加载。共享课程脚本和单文件教程无需更新备份逻辑。

# 好奇心小站

适合 iPad 和电脑的轻量学习站：

- 数学：圆的周长、面积及与正方形组合的互动演示，5 道强化练习。
- 数学：迷你火箭比例尺，含缩放动画、单位换算与正反推算，5 道强化练习。
- 数学扩展：9 个果子找更重者，可操作天秤、最少次数的推理与 5 道多维度练习。
- 语文：直接引语改转述句的技巧与 5 道强化练习。
- 英语：机器人小狗主题的口语与词汇练习，5 个小任务。
- 探索：火箭为什么要回收，含一级回收动画、可调模拟账本与 5 道强化题。
- 探索：两张图都没造假，为什么结论相反？先判断，再拖动柱状图纵轴验证；共 5 题，涵盖读图、增幅、辨错、迁移与独立表达。结束页保留本次首答和帮助使用情况，便于截图反馈；刷新后清除，不上传。

首页以「TY敏捷课堂」承载数学、语文、英语，以「马斯克的太空学校」提供选学探索课。

用 Safari 打开网站，选择「分享 → 添加到主屏幕」。首次联网完整打开后，站内核心内容可离线访问。英语示范音频随站点提供；口语录音只保留在当前页面内存中，不上传，离开后清除。

这是无需构建的静态网站。GitHub Pages 从 main 分支根目录发布；所有资源使用相对路径。更新内容时同步调整 sw.js 中的缓存版本。

## 学习反馈

所有七课均保持固定 5 题 / 任务。六门旧课已补齐本次反馈页：保留首次提交、重试次数、答前 / 答后的提示和回看，以及综合题原话。数学、比例尺、天秤和语文将一句理由融入原有第 5 题；火箭课保留建议表达；英语第 3、4 题文字可选，第 5 题留一句英语原话。均可如实选择暂时不会或仍需帮助，不额外增加第 6 题。

- 反馈只存在当前页面内存中，不使用服务器或持久化存储；刷新、重开或离开前先截图。外部求助无法自动识别，未打开帮助不等于已经独立掌握。
- 天秤反馈还记录称量、重新开局和自动摆法；重新开局保留本题之前的尝试。
- 英语首段录音可在反馈页回听，重录保留首段；主动删除会清除相应录音，离开页面也会清除。没有自动转写或语音评分，截图仅含文字证据与使用情况。
- `learning-feedback.js` / `.css` 提供共享记录与样式；为保留单文件离线能力，`lessons/chinese.html` 和 `lessons/math.html` 的 sandbox srcdoc 内嵌相同代码。更新共享逻辑时需同步这两份内嵌副本。图表课保留其已有反馈实现。

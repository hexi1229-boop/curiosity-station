# 好奇心小站

适合 iPad 和电脑的轻量学习站：

- 数学：圆的周长、面积及与正方形组合的互动演示，5 道强化练习。
- 数学：迷你火箭比例尺，含缩放动画、单位换算与正反推算，5 道强化练习。
- 数学扩展：9 个果子找更重者，可操作天秤、最少次数的推理与 5 道多维度练习。
- 数学衔接：负数乘负数，为什么是正数？四步分配律推理与正负配对动画，固定5题包含异号小数、乘零、解释及过去时间方向的迁移。
- 数学衔接：减去负数，为什么反而变大？两种同尺度数轴表示，固定5题，覆盖有向差、加相反数、结果仍为负、小数计算和撤销扣分的迁移。
- 数学衔接：零下8℃和零下3℃，哪里更暖？先判断，再调节同尺度温度计与数轴，固定5题区分数的大小、相反数与绝对值，迁移到海面下的位置比较。
- 数学衔接：神秘货箱有多重？用天秤解释等式变形，固定5题，包含理由、纠错、实际应用和代回原式检验。
- 物理衔接：更重的积木，材料就更“密”吗？调节体积、比较同体积质量，固定5题含切半解释、密度计算、反求质量和模型选材；真实器材操作仍待办。
- 物理衔接：跑得远，就一定更快吗？同坐标匀速模拟、改变用时、固定5题，覆盖平均速度比较、总路程与总时间、单位换算和途中停留。
- 生物衔接：没有叶绿体，就不是植物细胞吗？切换洋葱内表皮、绿色叶肉与口腔上皮示意模型，固定5题覆盖结构证据、功能定位、共同点与分类迁移。
- 生物衔接：一颗番茄，是组织还是器官？逐层查看植株、果实、组织与细胞，固定5题，含层次点按排序和叶片/胃的新情境解释。
- 化学衔接：水蒸发了，分子也变大了吗？密闭水分子分布模型，固定5题区分分子大小、间隔、数量边界及凝结白雾；两题开放解释不自动判分。
- 化学衔接：冒泡了，就一定发生化学变化吗？固定5题，比较沸腾与电解的粒子模型，区分现象和新物质证据，再迁移到变色与蜡烛两个过程。
- 地理衔接：两条上山路，哪条更陡？同一山丘的等高线与同尺度侧面图联动，固定5题覆盖陡缓依据、海拔范围、相对高度和不同地图比例尺的迁移比较。
- 地理衔接：地图转了，北方也会跟着转吗？转动地图与指北标，固定5题，区分屏幕方向与地理方向、交换参照点、量算路线距离并独立写路线。
- 语文：直接引语改转述句的技巧与 5 道强化练习。
- 语文阅读：一句话说清整件事。原创短消息、概括编辑台和信息卡取舍，固定5题含遗漏解释、范围辨错与新材料独立概括；开放概括按要点自检，不做关键词自动评分。
- 语文阅读：这句话能证明你的答案吗？原创短文、证据连线演示，固定 5 题，涵盖找依据、解释、辨错、迁移和独立短答。两道开放题不自动判分。
- 英语衔接：昨天的试飞，怎么用英语讲清楚？原创听读记录、四种时间/句式对照和词牌组句，固定5题含纠错解释、词义迁移与口述。口述不录音，保留文字原话，不自动判定发音。
- 英语：机器人小狗主题的口语与词汇练习，5 个小任务。
- 探索：火箭为什么要回收，含一级回收动画、可调模拟账本与 5 道强化题。
- 探索：两张图都没造假，为什么结论相反？先判断，再拖动柱状图纵轴验证；共 5 题，涵盖读图、增幅、辨错、迁移与独立表达。结束页保留首答和帮助使用情况，便于截图反馈；记录自动保存在本机，不上传。

首页以「TY敏捷课堂」承载数学、语文、英语、物理、化学、生物、地理，以「马斯克的太空学校」提供选学探索课。

用 Safari 打开网站，选择「分享 → 添加到主屏幕」。首次联网完整打开后，站内核心内容可离线访问。英语示范音频随站点提供；口语录音只保留在当前页面内存中，不上传，离开后清除。

这是无需构建的静态网站。GitHub Pages 从 main 分支根目录发布；所有资源使用相对路径。更新内容时同步调整 sw.js 中的缓存版本。

英语巩固《平时常做，还是此刻正在做？》用日常周历和当前镜头区分习惯与进行中的动作，固定5题含解释、形式纠错、双空组合与两句英语口述迁移。该课口述不录音，保留文字原话与自检，不能自动判定发音或流利度。

## 学习反馈

所有二十三课均保持固定 5 题 / 任务。六门旧课已补齐本次反馈页：保留首次提交、重试次数、答前 / 答后的提示和回看，以及综合题原话。数学、比例尺、天秤和语文将一句理由融入原有第 5 题；火箭课保留建议表达；英语第 3、4 题文字可选，第 5 题留一句英语原话。均可如实选择暂时不会或仍需帮助，不额外增加第 6 题。

- 首页「学习记录」按课程和时间查看每次练习，未完成记录也能展开截图。首次答案、重试、帮助、原话及未提交草稿边做边存；刷新后继续未完成题目，重做 5 题另存一次，保留旧记录。
- 使用当前浏览器的 localStorage，不发送作答内容到服务器。换设备、换浏览器或从 Safari 换到独立桌面入口，不保证共享记录；清理网站数据会清除。存储受限或已满会显示保存失败，不自动删旧记录。外部求助无法自动识别，未打开帮助不等于已经独立掌握。
- 天秤反馈还记录称量、重新开局和自动摆法；重新开局保留本题之前的尝试。刷新会恢复该局的偏重果子、摆法、候选与称量次数。
- 英语首段录音可在反馈页回听，重录保留首段；主动删除会清除相应录音，离开页面也会清除。没有自动转写或语音评分，截图仅含文字证据与使用情况。
- `learning-feedback.js` / `.css` 提供共享记录与样式；为保留单文件离线能力，`lessons/chinese.html` 和 `lessons/math.html` 的 sandbox srcdoc 内嵌相同代码。更新共享逻辑时需同步这两份内嵌副本。图表课接入同一记录库，保留其判断与坐标轴实验流程。
- 圆课维持 `sandbox="allow-scripts"`：外层注入仅圆课的已有记录，内层通过校验 iframe 来源的 postMessage 保存到同源记录库，不开放同源沙箱权限。
- 记录格式带版本号，每次练习独立存储键；读取时跳过不可读记录并原样保留。服务工作线程更新只替换静态资源缓存，不清除学习记录。

## 导出与恢复

学习记录页提供「导出学习记录」和「导入备份」，不改变孩子的自动保存或固定 5 题流程。

- 导出当前入口的全部课程、全部练习为一个带时间的 UTF-8 JSON 文件，不受课程筛选影响。可直接发给 AI 分析，或保存在 iPad「文件」中；不含录音。
- 新设备打开同一小站，在学习记录页导入文件。原话、首答、帮助、草稿、时间和续练状态一并恢复。导入过程在设备内完成，不上传文件。
- 文件格式为 `curiosity-station-learning-backup`，版本 1。导入先校验完整文件，再追加记录；不覆盖已有键。使用内容指纹去重，导入记录采用确定性 ID，继续学习后重复导入旧文件也不会重复添加该快照。不同进度另存，显示「备份恢复」。
- 文件损坏、格式不兼容或超过 20 MB 时不导入；写入空间不足时显示已导入与尚未写入的数量，保留原文件可重试。记录不会自动同步，清理网站数据前应先导出。
- `learning-backup.js` 仅由记录页加载。共享课程脚本和单文件教程无需更新备份逻辑。

## 首页与课程库

首页保持一个继续入口、两门主科推荐和一门探索课，不随课程数量增长。`catalog.js` 存放学科、阶段和知识点，稳定课程 ID/标题/地址仍由 `learning-feedback.js` 管理；课程库支持组合筛选与关键词搜索。

继续入口读取本机各课程的最新练习，优先最近未完成的课程；推荐优先未完成练习的主科，不把完成状态等同掌握程度。没有记录时先推荐目录中的最新主科课。`records.html` 保留导出/导入，添加同样的三项导航。

阅读课第 1 题先作答，之后可看证据连线；第 2、5 题提交原话后才展示参考与自检，修改另记，提示分时机记录。刷新继续未完成题，草稿自动恢复；新课使用原来的记录格式和备份流程。网页、课程库和课程均加入离线缓存，manifest、图标和原有课程 URL 不变。

新增课程在创建反馈前须登记自己的课程 ID、标题和路径，兼容首次访问时仍由旧 Service Worker 提供的反馈脚本。共享读取逻辑只对旧版 `other` 且标题与课程表完全一致的记录恢复课程归属，原始作答与时间不变；未知或冲突记录不猜测。

- `forces.html`：两个力一样大，就会互相抵消吗？物理受力对象、同线二力合成、平衡与相互作用，固定5题。

- `grid.html`：只差一个字母，地点能跑到哪儿？经纬网读数、动手定位、零纬度与局部图迁移，固定5题。

- `division.html`：细胞变多了，分工就会自动出现吗？生长、分裂、分化对比模型与遗传信息/新材料迁移，固定5题。

- `power.html`：3⁴是12吗？把乘方拆开看。正整数指数、底数/括号、分数/零与复制规则迁移，固定5题。

- `qualifier.html`：一个“约”字，为什么不能随便删？语境中的精度/范围/条件、选词与独立改写，固定5题。

- `supplies.html`：两瓶水，英语里究竟在数什么？分装模型、名词单复数、单位和much/many口语迁移，固定5题。

- `purity.html`：看起来一样，就是纯净物吗？成分分类模型、冰水辨错、微观图判断与过滤证据边界，固定5题。

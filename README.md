- 英语口语衔接：我选这个方案，但你能说服我改主意吗？先锁定首选，再听队友顾虑、追问关键缺口并依据新事实调整或坚持，最后换成科技展任务独立迁移。

- 数学衔接：减去负数，为什么反而变大？两种同尺度数轴表示，固定5题，覆盖有向差、加相反数、结果仍为负、小数计算和撤销扣分的迁移。
- 数学衔接：零下8℃和零下3℃，哪里更暖？先判断，再调节同尺度温度计与数轴，固定5题区分数的大小、相反数与绝对值，迁移到海面下的位置比较。
- 数学衔接：神秘货箱有多重？用天秤解释等式变形，固定5题，包含理由、纠错、实际应用和代回原式检验。

- 生物衔接：没有叶绿体，就不是植物细胞吗？切换洋葱内表皮、绿色叶肉与口腔上皮示意模型，固定5题覆盖结构证据、功能定位、共同点与分类迁移。
- 生物衔接：一颗番茄，是组织还是器官？逐层查看植株、果实、组织与细胞，固定5题，含层次点按排序和叶片/胃的新情境解释。
- 化学衔接：水蒸发了，分子也变大了吗？密闭水分子分布模型，固定5题区分分子大小、间隔、数量边界及凝结白雾；两题开放解释不自动判分。

- 语文阅读：这句话能证明你的答案吗？原创短文、证据连线演示，固定 5 题，涵盖找依据、解释、辨错、迁移和独立短答。两道开放题不自动判分。
- 英语衔接：昨天的试飞，怎么用英语讲清楚？原创听读记录、四种时间/句式对照和词牌组句，固定5题含纠错解释、词义迁移与口述。口述不录音，保留文字原话，不自动判定发音。

- 探索：火箭为什么要回收，含一级回收动画、可调模拟账本与 5 道强化题。
- 探索：两张图都没造假，为什么结论相反？先判断，再拖动柱状图纵轴验证；共 5 题，涵盖读图、增幅、辨错、迁移与独立表达。结束页保留首答和帮助使用情况，便于截图反馈；记录自动保存在本机，不上传。

## 导出与恢复

学习记录页提供「导出学习记录」和「导入备份」，不改变孩子的自动保存或各课现有学习流程。

- 导出当前入口的全部课程、全部练习为一个带时间的 UTF-8 JSON 文件，不受课程筛选影响。可直接发给 AI 分析，或保存在 iPad「文件」中；不含录音。
- 新设备打开同一小站，在学习记录页导入文件。原话、首答、帮助、草稿、时间和续练状态一并恢复。导入过程在设备内完成，不上传文件。
- 文件格式为 `curiosity-station-learning-backup`，版本 1。导入先校验完整文件，再追加记录；不覆盖已有键。使用内容指纹去重，导入记录采用确定性 ID，继续学习后重复导入旧文件也不会重复添加该快照。不同进度另存，显示「备份恢复」。
- 文件损坏、格式不兼容或超过 20 MB 时不导入；写入空间不足时显示已导入与尚未写入的数量，保留原文件可重试。记录不会自动同步，清理网站数据前应先导出。
- `learning-backup.js` 仅由记录页加载。共享课程脚本和单文件教程无需更新备份逻辑。
